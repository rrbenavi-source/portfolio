The witness, in code

A query that compares the model's KPI against the ledger after every load and writes the result to a control table.

-- Witness: net sales from the model against the ledger, by company code and period
INSERT INTO control.reconciliation
SELECT CURRENT_TIMESTAMP, 'NET_SALES', f.company_code, f.period,
       COALESCE(m.net_sales, 0)                    AS model_value,
       f.ledger_balance                            AS source_value,
       CASE WHEN ABS(COALESCE(m.net_sales,0) - f.ledger_balance)
            <= t.tolerance_pct * ABS(f.ledger_balance)3
            THEN 'OK' ELSE 'EXCEPTION' END AS status4
FROM (SELECT company_code, period,
             -1 * balance AS ledger_balance2  -- revenue = credit
      FROM source.ledger_balances
      WHERE account_group = 'NET_SALES') f
LEFT JOIN model.sales_by_company m1
       ON m.company_code = f.company_code AND m.period = f.period
JOIN control.tolerances t ON t.kpi = 'NET_SALES';
1
Starts from the ledger, not the model. The company code that fell outside the filter shows up as an exception instead of vanishing.
2
Flips the sign. In ACDOCA sales are credits and live as negatives; without this, everything fails on day one.
3
The business signs the tolerance. It lives as data in control.tolerances, not buried in code.
4
The status gets published. The column that lands on the dashboard so the controller doesn't reconcile by hand.
