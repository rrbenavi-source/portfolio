Same question, four languages

“Quarter sales versus the same quarter last year, by region.” Who writes it changes. Someone still has to decide what “last year” means.

SQL
The bedsheet and the universeWritten by IT, or generated by the universe.
SELECT r.region,
       SUM(CASE WHEN f.anio = 2026 THEN f.venta_neta END) AS venta_2026,
       SUM(CASE WHEN f.anio = 2025 THEN f.venta_neta END) AS venta_2025
FROM   fact_ventas f JOIN dim_region r ON r.region_id = f.region_id
WHERE  f.trimestre = 3 AND f.anio IN (2025, 2026)
GROUP BY r.region;
MDX
The cube“Prior year” is a function of the engine.
WITH MEMBER [Measures].[Venta AA] AS
  ( [Measures].[Venta Neta],
    PARALLELPERIOD([Fecha].[Fiscal].[Año], 1,
                   [Fecha].[Fiscal].CurrentMember) )
SELECT { [Measures].[Venta Neta], [Measures].[Venta AA] } ON COLUMNS,
       [Región].[Región].Members ON ROWS
FROM   [Ventas] WHERE [Fecha].[Fiscal].[2026].[T3]
